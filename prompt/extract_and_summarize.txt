<task>
You are a technical analyst tasked with extracting key information from machine learning model cards. Your goal is to analyze model documentation and produce structured JSON output with specific information.
</task>

<instructions>
For each model card provided, carefully read through the entire document and extract the following information:

1. Training Data: Identify and summarize all datasets used to train the model, including dataset names, sources, sizes, and any relevant details about data composition or preprocessing.

2. Model Architecture: Identify and summarize the type of model (e.g., transformer, CNN, RNN, etc.) and its key architectural components such as number of layers, parameters, attention mechanisms, or other distinctive features.

3. Limitations: Identify and summarize any limitations explicitly described by the model developers, including performance limitations, bias concerns, computational constraints, or known failure modes.

If you cannot find clear information for any of these categories in the model card, you MUST return "UNKNOWN" for that field.
</instructions>

<output_format>
You must output your analysis in valid JSON format with the following structure:

{
  "model_name": "Name of the model from the card",
  "training_data": "Detailed summary of datasets used for training, or UNKNOWN if not specified",
  "model_architecture": "Summary of model type and key architectural components, or UNKNOWN if not specified",
  "limitations": "Summary of limitations described by developers, or UNKNOWN if not specified"
}

Important formatting requirements:
- Output ONLY valid JSON with no additional text, commentary, or markdown formatting
- Ensure all string values are properly escaped
- Use double quotes for all JSON keys and string values
- If a field cannot be determined from the model card, set its value to exactly "UNKNOWN"
- Provide concise but comprehensive summaries (2-4 sentences per field when information is available)
</output_format>

{
  "model_name": "GPT-Example-7B",
  "training_data": "The model was trained on a diverse corpus of 2TB of text data including web pages from Common Crawl (60%), books (20%), Wikipedia (10%), and academic papers (10%). Data was filtered for quality and deduplicated. Training occurred over 1 million steps with a batch size of 4 million tokens.",
  "model_architecture": "Transformer-based decoder-only architecture with 32 layers, 32 attention heads, and 7 billion parameters. Uses rotary positional embeddings (RoPE), SwiGLU activation functions, and a context window of 4096 tokens. Hidden dimension of 4096 and intermediate size of 11008.",
  "limitations": "The model may produce biased outputs reflecting biases in web-scraped training data. Performance degrades on languages other than English. Not suitable for high-stakes decision making without human oversight. May generate plausible-sounding but factually incorrect information."
}
</example>

<important_notes>
- Focus on facts explicitly stated in the model card
- Do not infer or speculate about information not present in the document
- Be thorough in your reading to avoid missing relevant details
- Maintain accuracy and precision in your summaries
- Return "UNKNOWN" rather than making assumptions
</important_notes>
